2. What Are Hooks in React? (Mental Model)

The Fishing Hook Metaphor · All 6 Essential Hooks · Live Interactive Playground

Expand Details ▼
Figure 2: The Hook Metaphor — Hooking Pure Functions into React's Engine

✨ The 6 Essential Hooks to Remember:

1. useState State Memory

Remember data between renders. Calling the setter function updates the value and re-renders the component. 

const [count, setCount] = useState(0);
2. useEffect Side Effects

Runs code after rendering (API data fetching, timers, subscribing to websocket channels). 

useEffect(() => { loadCart(); }, []);
3. useContext Teleport Data

Skip "prop-drilling" through 10 parent components. Directly read global themes, auth, or cart states. 

const user = useContext(AuthContext);
4. useRef Secret Box

Holds a mutable value across renders without triggering a re-render. Also holds direct DOM node references. 

const inputRef = useRef(null);
5. useMemo Calculation Cache

Caches the result of an expensive calculation so it doesn't recalculate on every single render. 

const total = useMemo(() => calc(cart), [cart]);
6. useCallback Function Cache

Prevents function recreation on every render, keeping props stable for optimized child components. 

const click = useCallback(() => {}, []);

1. React 18 Concurrent Root

createRoot() replaces the legacy ReactDOM.render(). It allows React to pause, resume, and prioritize renders so complex UI interactions remain silky smooth.

2. Why StrictMode Runs Twice

If you see a console.log() print twice in your dev tools, that is <React.StrictMode> doing its job! It intentionally mounts twice in dev mode to verify your cleanup logic works. In production, it only runs once!

Standard JavaScript DOM lookups can return null. The type assertion tells TypeScript to treat the result strictly as a non-null HTML element, keeping your build clean of null checks.

  const updated = await api.updateCartItem(cartItemId, quantity);

};

// Clerk 3: Apply promotional discount
const handleApplyCoupon = async (code: string) => {
  try {

    setCart(updated);
  } catch (err: any) {

📖 The Story of the Abacus & The Anti-Pattern Trap

Notice line 13 does NOT use useState to store totalItems!
• The Anti-Pattern Trap: If you stored totalItems in its own useState, you would have to sync it with useEffect every time cart changed, causing duplicate renders and out-of-sync badge counts.

• cart?.items (Optional Chaining): Safely evaluates to undefined if cart is still null, preventing crashes.
• .reduce((sum, it) => sum + it.quantity, 0): Loops over all cart items (e.g. 2 Oak Chairs + 1 Velvet Sofa = 3 total items).
• || 0: Fallback default to ensure totalItems is always a valid number. 

const navigate = useNavigate();
const totalItems = cart?.items.reduce((sum, it) => sum + it.quantity, 0) || 0;
